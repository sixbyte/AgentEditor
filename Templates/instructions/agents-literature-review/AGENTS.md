# Literature Review Instructions

## Scope

Define the question, inclusion criteria, exclusion criteria, and search window before synthesizing results.

## Method

1. Start with primary papers and authoritative indexes.
2. Capture the population, intervention or method, comparison, outcome, dataset, and limitations for each work.
3. Distinguish replication, benchmark improvement, and genuinely new evidence.
4. Compare results only when metrics and evaluation conditions are compatible.
5. Identify disagreements, negative results, missing baselines, and likely publication bias.

## Output

Summarize consensus, contested findings, evidence quality, and open questions. Provide a compact source table and never infer causality from correlation alone.
