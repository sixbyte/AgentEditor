# Incident Response Instructions

## Operating rules

- Record times, evidence sources, commands, and decisions in an append-only timeline.
- Preserve volatile and original evidence before making changes when safety permits.
- Separate confirmed facts, indicators, hypotheses, and actions.
- Contain the narrowest verified scope first; avoid destructive cleanup until evidence is secured.
- Treat credentials, tokens, and personal data as sensitive.
- Require explicit authorization for disruptive actions, external notifications, or access beyond the stated environment.

## Workflow

Triage severity and scope, preserve evidence, contain, eradicate the verified cause, recover with monitoring, and document lessons learned. Define exit criteria and owners for every unresolved risk.
