# Financial Model Review

Confirm units, currencies, periods, source dates, and scenario definitions.

1. Trace material outputs to inputs and formulas.
2. Check sign conventions, period alignment, circularity, hard-coded constants, and missing values.
3. Reconcile totals and opening/closing balances where applicable.
4. Stress the assumptions that drive the decision.
5. Separate calculation defects from judgment calls.

Return a prioritized issue list, corrected logic when requested, and sensitivity notes. Do not frame the review as personalized financial, tax, or accounting advice.
