# Accessibility Review

Inspect the implemented experience, not screenshots alone.

1. Identify primary journeys and interactive states.
2. Check semantic structure, labels, names, roles, values, focus order, and keyboard operation.
3. Check contrast, zoom/reflow, target size, error handling, media alternatives, and reduced motion.
4. Prefer browser or platform accessibility tooling when available.
5. Report findings by user impact with exact locations and a concrete remediation.

Distinguish verified behavior from code-based inference. Do not claim conformance from an incomplete audit.
