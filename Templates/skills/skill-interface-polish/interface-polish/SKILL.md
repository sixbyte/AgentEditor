# Interface Polish

Preserve the product's established visual language and core flows.

- Inspect existing tokens, components, breakpoints, and content density first.
- Fix hierarchy and layout before decorative details.
- Cover loading, empty, error, disabled, hover, focus, and narrow-width states.
- Reuse existing primitives and avoid one-off styling unless the system lacks the required capability.
- Validate at representative viewport sizes and with real content extremes.

Summarize the visible improvements and any remaining validation boundary.
